Design Principles

OBSIDIAN is not a dashboard. It is a piece of theater — an institutional interface that makes surveillance, order and inevitability feel tangible.

PrincipleHow it shows up
I. Absolute toneShort declarative copy. Data before adjectives. The Empire does not explain — it commands.
II. Depth, not clutterOne canvas galaxy behind everything; surfaces stay flat and legible. Nothing overlaps content.
III. Ritual entryGate → typed boot → passphrase → welcome. Entry is a ceremony, not a login form.
IV. Every pixel intentionalCorner brackets, hairline borders, red accents used only for action and alarm.
V. Motion with meaningScramble text = decryption. Count-ups = live telemetry. Magnetic buttons = the interface feels alive.
VI. Original by defaultEvery glyph, sigil and component is designed in-house — no icon packs, no templates.

Microcopy & Feedback

Every action answers: escalate → "REPORT ESCALATED — OPERATION CREATED"; transmit → "TRANSMISSION SENT — SECTOR TORVANE NOW RECEIVING"; drag → "OPERATION MOVED TO ACTIVE". Failure is recorded in-universe: "ACCESS DENIED — INCIDENT LOGGED".

Accessibility

AA contrast on all body text · keyboard-operable nav and forms · focus states via red border · custom cursor disabled under 768px · reduced-motion respected for the canvas.
